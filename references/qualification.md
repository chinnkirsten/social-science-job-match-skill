# 资格与证据判定

## 三个独立结论

| 判断 | 取值 | 用途 |
|---|---|---|
| 招聘状态 | open / closed / unknown | 当前是否存在可申请的具体职位 |
| 资格状态 | pass / fail / unknown | 当前证据是否覆盖该JD的必需条件 |
| 匹配优先级 | A / B | 仅在前两项通过后比较投递顺序 |

主清单只能纳入 open + pass。这里的pass仅指符合公开JD及已知用户条件，不意味着雇主接受申请、仍有实际名额或保证面试。保留证据范围和核验时间。

## 招聘模式是第一道硬条件

每条岗位先判断是实习、应届校招全职还是社招全职，然后才评估专业和能力。岗位模式与本轮 `employment_mode` 不一致时不得进入主清单，即使职责高度匹配也不例外。

- 应届校招全职须有全职雇佣及校招/应届届别证据；只写“在校生、每周到岗、实习几个月、日薪”的岗位是实习。
- “可转正”不把实习改成校招全职；“校招频道”也不自动把频道内的实习改成全职。
- 通用全职岗若没有明确届别，只有在读完全JD并确认经验、毕业时间和入职要求与应届候选人兼容后，才可在 `campus_full_time` 模式下评为pass。

## 逐项判定，不能靠总分弥补

- 完整读取JD，逐项拆出必需条件、偏好项及可替代条件，并附来源位置和简短原文。至少覆盖所有必需条件；“3项对照”只是正文展示下限，不能只挑最容易满足的3项。
- “必须、熟练掌握、任职要求”中的实质能力默认作为必需项评估；“优先、加分、或愿意学习”按原意处理。含糊且会影响纳入结果的，记unknown，不自行降级。
- 区分可核验资格/能力与主观倾向。责任心、亲和力、行业热情等不能被伪装成已测评通过；用真实协作经历解释迁移依据，并在匹配风险中保留未验证的工作场景。纯兴趣偏好不等于要求已有该行业经验；但明确限定的经历、证书、工具、到岗承诺或用户明确拒绝的工作内容不能借此降级。报告说“符合已知公开条件”，不说“全部素质已经证明”。
- “会用Office”不能证明熟练做数据透视分析；AI辅助网页不能证明视频剪辑；外语分数不能证明某个特定证书已取得。只有JD明确接受替代条件时才按替代路径通过。
- 简历明示的熟练程度作为“申请人自述”使用，不冒充独立能力测评，也不因缺少作品就擅自降成基础水平。逐字核对技能栏与经历栏，避免PDF提取顺序遗漏；明确的预算、采购、分工等职责可以改写，未提供的金额、规模、成效不可补造。
- 必需项有直接证据为met；用户明确没有或与明确事实矛盾为unmet；简历未体现为unknown，而非断言用户不会。必需项中有unmet则fail，无unmet但有unknown则unknown，其余为pass。
- 应届届别、毕业窗口、年级、专业、天数与时长各自判定。不能用入学年份猜毕业年；未来课程不能当作已掌握技能；用户愿意灵活安排不代表已确认具体到岗日。
- “通常不限制年级”等招聘惯例不能补充JD。JD只要求本科在读且无明确届别限制时，可按该公开条件评估，但不要写雇主明确接受所有年级。
- 申请页面的必填材料和筛选问题也是条件来源。登录、隐私同意或上传之后的步骤未经授权不进入；看不到后续要求就说明核验边界。普通登录入口可作为申请路径，不等于已测试提交成功。

## 开放证据与冲突

页首与正文不完全相同不一定矛盾。例如“5天/周”与“至少3天/周”可以同时满足，应保留两种口径并按可兼容的安排评估；“大四优先”也不等于限制其他年级。只有无法同时满足、含义不清且影响资格，或具体办公点尚无证据等情况才因冲突待确认，不能机械地把任何文本差异当成阻断。

公开JD + 当前具体岗位申请状态或有效截止信息 + 未发现关闭信号，才能记open。通用“投递”按钮、刷新日期、HTTP 200都不能独立支持open。官方关闭信号优先于镜像“在招”；两个官方来源矛盾时记unknown并保留双方，不按想要的结论挑一个。

刷新日期不等于初次发布日期；截止日只有日期时记录原文日期和雇主时区，截止当天或时区不明时提示风险，不擅自补23:59。结构化检查使用带时区的核验时间，默认要求交付前24小时内核验；这是本技能的证据新鲜度要求，不是职位有效期承诺。接近截止或发现变化时仍需重新打开来源。

## 去重与搜索覆盖

优先用雇主岗位ID识别同岗；无ID时用发布主体、规范化标题、地点识别，URL去追踪参数后辅助比较。保留原始可用链接，不为规范化破坏ATS路由。

公司数量使用稳定company_key，同公司多岗只计一次；集团内不同品牌、分公司或主体关系不清时保守合并，并说明计数依据。学校、基金会等不冒充企业。真实不同企业也不能仅因中英文别名差异重复计算。

记录检索方向和淘汰原因；没有找到匹配的研究岗位可以明确说明，不应拿大量内容营销岗暗示它们适合所有社科学生。扩展仍不足20家时交付阶段结果，列出缺口，不制造满额结果。
